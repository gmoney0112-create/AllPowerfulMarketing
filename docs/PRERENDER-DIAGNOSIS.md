# Prerender Diagnosis

The site was a pure Create React App single-page application using hash-based routing (`/#/about`, `/#/services`, etc.) with no server-side or static prerendering. Every route served the same root `index.html` shell containing only a `<div id="root"></div>` and a single bundled JavaScript file — search engine crawlers received zero meaningful HTML content on any page. The fix converts routing to react-router-dom BrowserRouter with path-based URLs, adds `public/404.html` to handle GitHub Pages' lack of a catch-all server, adds `react-helmet-async` for per-route `<head>` management (unique title, description, canonical, OG, JSON-LD), and wires `react-snap` as a `postbuild` script to crawl all 11 routes and emit pre-rendered HTML files so every page ships with fully-populated `<head>` and body content before any JavaScript executes.
